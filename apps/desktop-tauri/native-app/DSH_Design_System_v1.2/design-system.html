04 / Critical UX patterns

Một flow phải giúp người dùng biết chuyện gì đã xảy ra, có quyền quyết định hay không, và điều gì là thật từ runtime.

01 / Healthy run
Read → Change → Verify
1Inspect source / show evidence
2Apply explicit, bounded edits
3Run checks / attach outcomes
4Review actual diff, no fake pass
02 / Human in control
Approval with exact scope
1Explain tool, target and risk
2Allow once / Deny, only
3Wait for Host acknowledgment
4Display truthful outcome
03 / Recovery
Failure is a state, not a dead end
1Name what failed and why
2Keep draft, selection and context
3Offer safe retry / copy details
4Reconcile with actual Host state
